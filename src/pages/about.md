## NETZY / AI Security

NETZY, aka Netzy. **hackthebrain.dev**는 AI Security를 중심으로 연구와 기술 기록을 연결하는 개인 블로그입니다.

LLM 기반 애플리케이션의 보안 진단에서 관찰한 현상을 검증 가능한 위협 시나리오로 발전시키는 과정에 관심을 두고 있습니다. [공개 LLM 진단 회고](/posts/llm-security-assessment-build-vulnerabilities/)에는 도구 실행 검증, 재현성, 업무 영향과 개발팀과의 소통에서 얻은 고민을 담았습니다.
